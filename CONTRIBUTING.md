# Contributing to GexRecompiled

## Feedback

Any launch reports on any platforms and all constructive criticism is welcome.

## Bug reporting

Describe what happened, what you expected and how to reproduce it. Include
the platform, build, renderer and relevant level or scene. Logs, screenshots
or short recordings are helpful when available.

## Project direction

Gameplay and audiovisual correctness, stability and performance are important
areas for improvement. The aim is to preserve the original game's behaviour
and presentation while making it usable on the supported platforms.

See the [README](README.md) for the current scope, limitations and planned
features.

## Usage of LLMs

Allowed due to the project being AI-led. Usage of AI-generated assets is
forbidden to maintain presentation.

## Making changes

Keep changes focused and avoid unrelated rewrites or cleanup.

Test the affected behaviour and report what you checked, along with remaining
limitations. Add a regression test for a reproduced bug when practical.
Make fixes reproducible rather than relying on hand-edited generated sources
or local dependency changes.

## Original game and assets

Use your own authorised game installation. Do not include the original
executable or game assets in contributions, and do not modify them to hide
a problem in the recompilation.

## Technical documentation

Setup, source generation, build instructions and implementation details belong
in the [development guide](docs/development.md). Detailed testing procedures
are in the [testing skill](.github/skills/testing/SKILL.md).
