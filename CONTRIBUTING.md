# Contributing to GexRecompiled

## Feedback

Any launch reports on any platforms and all constructive criticism is welcome.

## Bug reporting

Describe what happened, what you expected and how to reproduce it. Include the platform, build, renderer and other configuration if relevant. Logs, screenshots and recordings are helpful when available.

## Project direction

The goal is to preserve the original game's behaviour and presentation while offering an improved experience on the supported platforms.

Consult the [README](README.md) for the planned features.

## Usage of LLMs

Allowed due to the project being AI-led. Usage of AI-generated assets is forbidden to maintain presentation; all custom assets like the project logo and program icon are manually edited.

## Making changes

Keep changes focused and avoid unrelated rewrites or cleanup.

Test the affected behaviour and report what you checkeds. Add a regression test for a reproduced bug when practical.
Make fixes reproducible rather than produciong hand-edited recompiled code.

## Original game and assets

Use your own local legally obtained game installation. Do not include the original executable or game assets in contributions, and do not modify them to hide a problem in the recompilation.

## Technical documentation

Setup, source generation, build instructions and implementation details belong in the [development instructions for agents](docs/development.md). Detailed testing procedures are outlined in the [testing skill](.github/skills/testing/SKILL.md).
